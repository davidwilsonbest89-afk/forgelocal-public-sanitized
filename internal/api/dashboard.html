Interface historique désactivée

Cette ancienne interface BrowseForge est volontairement indisponible. Elle ne peut plus recevoir, afficher ou stocker un jeton Bearer principal.

Utilisez le dashboard ForgeLocal avec une session lecture seule temporaire. Depuis la machine locale du Core, générez un code à usage unique :

forgelocal readonly-session code

Le code expire rapidement, ne donne accès qu’aux endpoints lecture seule et ne doit jamais être conservé dans le navigateur.
