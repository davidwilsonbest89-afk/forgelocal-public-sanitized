BrowseForge MCP Web Session Call Flow

Final architecture

  • Chrome/CloakBrowser profiles are the supported browser path for web_search and web_explore.
  • One profile browser is owned by browser.Manager.
  • Each MCP agent session connects through the profile browser's Playwright Bind endpoint.
  • Each agent session owns one independent Page, created with connectedBrowser.NewPage().
  • GC and destroy_session close only the agent Page and remove metadata.

  I -->|no| H
  H --> M{Profile engine chromium?}

  N --> O[Use browser.Session.ConnectURL]
  O --> P[pw.Chromium.Connect ConnectURL]
  P --> Q[connectedBrowser.NewPage]
  Q --> R[Store WebSession metadata]
  R --> L

  L --> S{Operation}
  S -->|Search| T[Resolve search provider]
  T --> V[Page.Goto provider search URL]
  S -->|Explore| U[Page.Goto target URL]
  V --> VA[Extract structured results]
  U --> W[Extract title/text/links]
  VA --> Y[Return content plus session_id profile_id session_created engine]
  W --> Y

  Z[destroy_session / GC / CloseAll] --> ZA[Close WebSession.Page]
  ZA --> ZB[Delete SessionPool metadata]
  ZB -. never closes .-> ZC[browser.Manager-owned profile browser]

Lifecycle guarantee

SessionPool never owns the profile browser. It owns only the MCP agent session metadata and the independent page opened for that session.
